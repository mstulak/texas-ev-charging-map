# Texas EV charging prices map

Public EV chargers in Texas with the prices that can be verified (USD/kWh). Unknown prices stay grey; third-party prices are flagged as inferred.

Live: https://mstulak.github.io/texas-ev-charging-map/

Data: U.S. DOE Alternative Fuels Data Center station list (public domain), operator websites (Mercedes-Benz HPC, IONNA, Austin Energy), prices the hosts reported to the DOE database, and flagged secondary sources (Tesla, Electrify America, Rivian). Map tiles © Esri / OpenStreetMap contributors. Single self-contained HTML file (`index.html`).
